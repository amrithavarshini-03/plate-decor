# BRB Decors — Placeholder Image Directory

Welcome! This folder holds the imagery for the BRB Decors website. 
When your real high-resolution event photographs are ready, you can drop your photos directly into this folder or replace the files listed below.

## Recommended Specifications
- **Format**: `.webp`, `.jpg`, or `.png`
- **Aspect Ratio**: 
  - Plates / Arrangements: `1:1` (Square, 800 x 800 px or higher)
  - Stage Backdrops / Hero: `16:9` or `4:3` (1600 x 1200 px or higher)
- **Quality**: Clean lighting, showing fresh leaves, bright marigolds, and intricate details.
